Bingung bikin sitasi?

Jangan mengetik daftar pustaka satu per satu jika kamu bisa mengelolanya dengan reference manager.

REFERENCE MANAGER

Gunakan tools untuk mengelola referensi

Z

Zotero

Zotero dapat digunakan untuk mengumpulkan, mengatur, memberi anotasi, dan membuat sitasi serta bibliografi. Zotero juga mendukung banyak citation styles. :contentReference[oaicite:4]{index=4}

M

Mendeley

Mendeley Reference Manager dapat membantu mengelola referensi, membaca dan memberi anotasi PDF, serta memasukkan sitasi dan bibliografi melalui Mendeley Cite. :contentReference[oaicite:5]{index=5}
